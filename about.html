ℹ️ About CodeKids

A CEP Project for Coding Awareness

🎯 Project Overview

CodeKids is a Coding Awareness Program designed for school children (aged 8–14) to understand the basics of programming in a fun, colorful, and interactive way.

🛠️ Technologies Used

✅ HTML5 — Structure of the website

✅ CSS3 — Styling, animations, responsive design

✅ JavaScript — Interactive quiz, games, pattern printing

✅ VS Code — Code editor

✨ Key Features

📚 Learn Section — Basics of coding with examples

🌐 Languages Section — Introduction to Python, Scratch, JavaScript, HTML, Java, C++

🌟 Famous Coders — Inspiring stories of Ada Lovelace, Alan Turing, Grace Hopper & more

🧠 Interactive Quiz — 7 questions with instant feedback and score

🎮 Games Gallery — Playable guess-the-number game and previews of future games

🎯 Learning Outcomes

• Understanding basic coding concepts

• DOM manipulation with JavaScript

• Event handling (clicks, inputs)

• Responsive web design with Flexbox & Grid

• CSS animations and transitions

🚀 Future Scope

• Add more playable games (Snake, Tic Tac Toe, Memory Match)

• Add sound effects and animations

• Add certificates for quiz completion

• Multi-language support (Hindi, Tamil, etc.)

• Backend to track student progress
